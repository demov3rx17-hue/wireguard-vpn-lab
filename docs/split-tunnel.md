# Client01: split tunnel

В конфигурации `client01` указано:

```text
AllowedIPs = 10.50.0.0/24, 192.168.20.0/24
```

Поэтому маршрут до `192.168.20.0/24` создан через `wg0`, а default route
остаётся через DHCP-шлюз VMware `192.168.239.2`.

Проверка показала:

```text
ip route get 8.8.8.8 -> via 192.168.239.2 dev ens33
traceroute 8.8.8.8  -> первый hop 192.168.239.2
ping 192.168.20.10  -> успешно через wg0
```
