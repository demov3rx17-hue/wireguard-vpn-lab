# WireGuard

На каждом узле создана отдельная пара ключей командой `wg genkey` и `wg
pubkey`. Приватные ключи лежат только в `/etc/wireguard/` соответствующей VM с
правами `600`; в репозитории их нет.

Сервер слушает `UDP/51820`. На сервере каждый peer ограничен своим адресом:

| Peer | Server-side AllowedIPs |
| --- | --- |
| `client01` | `10.50.0.2/32` |
| `client02` | `10.50.0.3/32` |

`AllowedIPs` одновременно определяет допустимый адрес peer и создаёт маршруты
на клиенте. Состояние проверяется командой `sudo wg show`: в ней должны быть
`latest handshake` и счётчики `transfer`.
