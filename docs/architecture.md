# Архитектура

`vpn-server` имеет два интерфейса:

- `ens33` — WAN через VMware VMnet8, адрес получает по DHCP;
- `ens34` — внутренняя сеть VMnet12, адрес `192.168.20.1/24`.

WireGuard работает на интерфейсе `wg0` с адресом `10.50.0.1/24` и UDP-портом
`51820`. VPN-клиенты находятся в VMnet8, поэтому используют WAN-адрес VPN
сервера `192.168.239.132:51820` как endpoint.

```text
client01 / client02 -- VMnet8 -- vpn-server -- VMnet12 -- internal-server
                                | wg0
                                +-- 10.50.0.1/24
```

`internal-server` уже имеет адрес `192.168.20.10/24` и шлюз
`192.168.20.1`, поэтому ответы VPN-клиентам возвращаются через `vpn-server`.
